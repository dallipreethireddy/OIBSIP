# BMI Calculator

## Project Description

The BMI Calculator is a Python-based program that calculates Body Mass Index (BMI) using weight in kilograms and height in meters. It displays the calculated BMI and its corresponding category.

## Features

- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI using the BMI formula
- Displays BMI rounded to 2 decimal places
- Displays BMI category
- Validates invalid input
- Rejects negative values
- Rejects zero height
- Allows the user to calculate BMI again

## BMI Formula

BMI = Weight / (Height × Height)

## BMI Categories

- Underweight: BMI less than 18.5
- Normal: BMI from 18.5 to 24.9
- Overweight: BMI from 25 to 29.9
- Obese: BMI 30 or above

## Technologies Used

- Python
- Python IDLE
- Built-in Python functions

## How to Run

1. Open Python IDLE.
2. Open `bmi_calculator.py`.
3. Press F5 or select Run → Run Module.
4. Enter the weight in kilograms.
5. Enter the height in meters.
6. The program displays the BMI and category.
