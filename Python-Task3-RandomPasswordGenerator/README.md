# Random Password Generator

## Project Description

The Random Password Generator is a Python-based program that generates random passwords according to the user's requirements. The user can specify the password length and select the types of characters to include.

## Features

- Minimum password length of 8 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- At least two character types required
- Input validation
- Option to generate another password

## Technologies Used

- Python
- random module
- string module

## How to Run

1. Open Python IDLE.
2. Open password_generator.py.
3. Press F5 or select Run → Run Module.
4. Enter the password length.
5. Select the character types.
6. The program generates a random password.

## Example

Password Length: 12

Character Types: 1,2,3,4

Generated Password: A7@kP2#mL9q!
